# 🚀 Cyber-Themed Developer Portfolio

> A futuristic, responsive, and interactive portfolio website built for a BCA student and system developer. Features a cyberpunk hacker aesthetic with dynamic terminal typing animations and a seamless Dark/Light theme switcher.

---

## ⚡ Tech Stack

* **Frontend:** HTML5, CSS3 (Custom CSS Variables), Vanilla JavaScript
* **Design Elements:** Glassmorphism UI, Grid/Flexbox layouts, Cyberpunk glow effects
* **Font:** Fira Code (Monospace)

---

## ✨ Key Features

* **Live Terminal Animations:** Continuous looping typing and erasing effect on headings with a glowing blinking cursor.
* **Theme Switcher:** Toggle between **Cyberpunk Dark Mode** (Neon Green theme) and **Sky Blue Light Mode** with persistent state saving (`localStorage`).
* **Distributed Content Sections:** Clean layout dedicated to Coding Knowledge, Gaming Interests, and Academic Course Info paired with distinct visual previews.
* **Interactive UI:** Mobile-responsive navigation, smooth scrolling, hover effects, and a working contact form layout.
